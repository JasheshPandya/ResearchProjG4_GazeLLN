Place one or more videos here, using any filename. Supported extensions: MP4, MKV, AVI, MOV, WebM, M4V, MPG, MPEG, WMV and Y4M (case insensitive).

Y4M (YUV4MPEG2) files are read directly; no conversion to MP4 is needed before encoding. Final compressed outputs are H.264 MP4 files.

Run `python Encoder/run_pipeline.py` from the project root. All videos are discovered automatically.
